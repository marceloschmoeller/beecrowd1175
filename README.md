# Exercício 1175 - Troca em Vetor I

## Descrição

Programa desenvolvido em Java que lê 20 números inteiros e os armazena em um vetor. Em seguida, inverte a ordem dos elementos, trocando o primeiro pelo último, o segundo pelo penúltimo e assim sucessivamente. Ao final, exibe o vetor na tela.

## Tecnologias utilizadas

- Java
- Apache NetBeans IDE
- Maven

## Entrada

O programa lê 20 números inteiros, um por linha.

## Saída

Exibe os 20 valores do vetor após a inversão, um por linha, no formato `N[i] = valor`, com índices de 0 a 19.
